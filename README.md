# レイアウト比率計算ツール

デザインカンプで測った外幅・左右パディング・テキスト・間隔・地図・画像の横幅（px）から、パディングを考慮した割合（%）とCSSを計算するWebアプリです。

## 使い方

1. このフォルダをVS Codeで開きます。
2. VS Code拡張機能「Live Server」をインストールします。
3. `index.html`を右クリックし、「Open with Live Server」を選びます。
4. デザインカンプで測った外幅と中の各横幅を入力します。左右パディングは任意入力です（空欄なら0px）。
5. 生成されたCSSを「CSSをコピー」ボタンでコピーします。

## 機能

- 入力と同時に割合を計算
- 左右パディングを外幅から差し引き、内側の幅を自動計算
- 左右パディングは外幅に対する割合、テキスト・間隔・画像は内側の幅に対する割合でCSS出力
- テキスト・間隔・地図・画像の比率を視覚表示
- 合計が100%かを自動判定
- Flex／Gridを切り替えてレイアウト用CSSを生成
- Flexではwidth・grow・shrinkを個別のコメント付きで生成
- 生成CSSをワンクリックでコピー
- スマートフォン表示に対応

外部ライブラリやビルド作業は不要です。HTML、CSS、JavaScriptだけで動作します。
